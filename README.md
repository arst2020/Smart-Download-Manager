# Smart Download Manager (SDM)

دانلود منیجر هوشمند و متن‌باز برای ویندوز، با C# و .NET 8.
فایل‌ها را چندتکه و سریع دانلود می‌کند و بعد از پایان دانلود، خودش آن‌ها را در پوشهٔ درست می‌گذارد؛
مثلاً `Dark.S01E03.1080p.mkv` به `Series\Dark\Season 01` منتقل می‌شود.

*An open-source smart download manager for Windows (C# / .NET 8). Segmented downloads with resume,
and automatic sorting of finished files — TV episodes go to `Series\<Show>\Season NN`.*

## امکانات نسخهٔ فعلی (MVP)

- دانلود چندتکه با ۱، ۴، ۸، ۱۶ یا ۳۲ کانکشن برای هر دانلود (پیش‌فرض ۳۲)؛ اگر سرور تعداد کانکشن را محدود کند (خطای 429 یا 503)، برنامه خودش تعداد را کم می‌کند
- ادامهٔ دانلود (Resume) بعد از توقف، بسته شدن برنامه یا قطع اینترنت؛ وضعیت هر ۲ ثانیه در `.sdmstate` ذخیره می‌شود
- اگر فایل روی سرور عوض شده باشد (ETag / حجم / Last-Modified)، دانلود از اول شروع می‌شود تا فایل خراب نشود
- تلاش مجدد خودکار برای هر تکه با فاصلهٔ زمانی فزاینده
- محدودیت سرعت کلی (Token Bucket)، صف با تعداد دانلود همزمان قابل تنظیم، پروکسی HTTP و SOCKS5
- دسته‌بندی هوشمند به ترتیب: **موضوعات کاربر ← تشخیص سریال ← نوع فایل**
  - سریال: `S01E03`، `s1e3`، `1x03`، `Season 1 Episode 3`، `فصل ۱ قسمت ۳`، `قسمت ۷`
  - اگر پوشه‌ای برای سریال یا فصل با نام کمی متفاوت از قبل وجود داشته باشد (مثل `The Office (US)` یا `S2`)، از همان استفاده می‌شود
  - نوع فایل: پسوند، امضای ابتدای فایل (Magic Bytes) و MIME
- امکان بازگرداندن (Undo) هر انتقال
- **دستیار هوشمند:** با وارد کردن لینک، پنجره‌ای باز می‌شود که می‌گوید محتوا چیست (سریال، فیلم، موسیقی، نرم‌افزار و غیره) و کجا ذخیره شود
  - هوش مصنوعی قابل انتخاب: Claude، OpenAI، Gemini، Ollama (محلی و رایگان) یا هر سرور سازگار با OpenAI
  - هوش مصنوعی فقط وقتی تشخیص محلی مطمئن نیست صدا زده می‌شود (یا برای همهٔ دانلودها، در صورت انتخاب در تنظیمات). فقط نام فایل، آدرس و عنوان صفحه ارسال می‌شود.
  - نام رسمی، سال و نام قسمت از **TMDB** گرفته می‌شود
  - اتصال به **Emby** یا **Jellyfin**: فایل در کتابخانهٔ مناسب (TV Shows، Movies، Music) ذخیره می‌شود و بعد از دانلود، کتابخانه اسکن می‌شود
  - تیک «تغییر نام استاندارد» (مثل `Dark - S01E03 - Secrets.mkv`) یا نگه داشتن نام فعلی
  - گزینهٔ «همیشه این عنوان را اینجا ذخیره کن» که خودکار یک قانون می‌سازد
- رابط کاربری WPF به سه زبان فارسی (راست‌به‌چپ)، انگلیسی و آلمانی، با **تم تیره و روشن** (یا هماهنگ با ویندوز)
- **پنجرهٔ پایان دانلود** با دکمه‌های «اجرا»، «باز کردن پوشه» و «بستن»
- **زمان‌بندی:** ساعت شروع و پایان (حتی از نیمه‌شب گذشته)، روزهای هفته، محدودیت سرعت در بازه، و کار بعد از تمام شدن صف (خواب، خاموش کردن، بستن برنامه)
- **افزودن دسته‌ای:** چند لینک را با هم کپی کنید و `Ctrl+V` بزنید یا روی «افزودن لینک» کلیک کنید؛ لینک‌های تکراری حذف می‌شوند و هر لینک جداگانه تشخیص داده می‌شود
- **نقشهٔ کانکشن‌ها:** پیشرفت هر تکه از فایل به‌صورت جداگانه
- پوستر فیلم و سریال از TMDB در پنجرهٔ افزودن
- **فهرست دانلودها ذخیره می‌شود:** بعد از بستن و باز کردن برنامه، لیست سر جایش است و دانلودهای نیمه‌کاره از همان‌جا ادامه پیدا می‌کنند (`%AppData%\SDM\downloads.json`). دکمهٔ «پاک کردن تمام‌شده‌ها» فقط لیست را خالی می‌کند و فایل‌ها حذف نمی‌شوند.
- **ناحیهٔ اعلان‌ها (System Tray):** با بستن پنجره، برنامه کنار ساعت ویندوز فعال می‌ماند (منو: باز کردن، افزودن لینک، توقف همه، خروج). وقتی پنجره پنهان است، پایان یا خطای دانلود با اعلان ویندوز خبر داده می‌شود؛ کلیک روی اعلان پنجرهٔ پایان دانلود را باز می‌کند.
- **کلیپ‌بورد هوشمند:** اگر در برنامهٔ دیگری لینک دانلود (ویدیو، فایل فشرده، برنامه، سند …) کپی کنید، پنجرهٔ کوچکی گوشهٔ صفحه می‌پرسد «دانلود شود؟». لینک صفحه‌های معمولی و عکس‌ها نادیده گرفته می‌شوند.
- **جستجوی زیرنویس:** برای فایل‌های ویدیویی، دکمهٔ «جستجوی زیرنویس» در پنجرهٔ پایان دانلود و منوی هر دانلود، صفحهٔ جستجوی سایت زیرنویس را با نام درست (مثلاً `Dark S01E03`) در مرورگر **فقط باز می‌کند**؛ برنامه هیچ زیرنویسی دانلود نمی‌کند. سایت در تنظیمات قابل تغییر است (SubDL، OpenSubtitles، Google یا هر آدرس دیگر با `{query}`).
- **FTP:** لینک‌های `ftp://` (ناشناس یا با `ftp://user:pass@host/file`) با ادامهٔ دانلود بعد از قطعی (REST)
- **چند صف:** علاوه بر صف اصلی، صف‌های دلخواه با تعداد دانلود همزمان و محدودیت سرعت جداگانه (مثلاً «شب»: یکی‌یکی با ۵۰۰ KB/s). صف در پنجرهٔ افزودن یا با راست‌کلیک ← «انتقال به صف» انتخاب می‌شود؛ با راست‌کلیک روی صف در نوار کناری، کل صف شروع یا متوقف می‌شود.
- **نمودار سرعت:** سرعت یک دقیقهٔ اخیر هر دانلود (با بیشینه و میانگین) و نمودار کوچک سرعت کل در نوار پایین
- **بررسی هش:** راست‌کلیک ← «بررسی هش»؛ هش MD5، SHA-1، SHA-256 یا SHA-512 فایل محاسبه و با هش اعلام‌شده در سایت مقایسه می‌شود (نوع هش از طولش تشخیص داده می‌شود)
- **استخراج خودکار:** فایل‌های `.zip` (داخلی) و `.rar`/`.7z`/`.tar.gz` (اگر [7-Zip](https://www.7-zip.org) نصب باشد) بعد از دانلود در پوشه‌ای کنار خودشان استخراج می‌شوند (اختیاری؛ چندبخشی‌ها فقط از بخش اول). «استخراج در همین‌جا» در منوی هر دانلود هم هست.
- **نصب‌کننده و نسخهٔ پرتابل:** فایل Setup (بدون نیاز به دسترسی Administrator، با گزینهٔ اجرا همراه ویندوز) و نسخهٔ Portable که تنظیمات و لیست را در پوشهٔ `Data` کنار خودش نگه می‌دارد
- **به‌روزرسانی خودکار:** هنگام اجرا آخرین نسخه از GitHub Releases بررسی می‌شود؛ نصب‌کنندهٔ جدید دانلود، با `SHA256SUMS.txt` همان نسخه بررسی و بعد از تأیید شما نصب می‌شود (در نسخهٔ پرتابل، صفحهٔ دانلود باز می‌شود). فقط فهرست عمومی نسخه‌ها خوانده می‌شود و هیچ اطلاعاتی ارسال نمی‌شود.
- خط فرمان `sdm` برای تست و اسکریپت

## افزونهٔ مرورگر

افزونه دانلودهای Chrome، Edge (و Firefox) را همراه با کوکی‌ها، Referer و User-Agent مرورگر به برنامه می‌فرستد؛ بنابراین سایت‌هایی که ورود لازم دارند یا برنامه‌های ناشناس را رد می‌کنند هم کار می‌کنند.

- گرفتن خودکار دانلودها (فایل‌های کوچک‌تر از حد تعیین‌شده در خود مرورگر می‌مانند؛ سایت‌ها را می‌توان مستثنا کرد)
- منوی کلیک‌راست: «دانلود با Smart Download Manager»، «دانلود همهٔ لینک‌های این صفحه» و «دانلود لینک‌های متن انتخاب‌شده» (پنجرهٔ افزودن دسته‌ای)
- اگر برنامه باز نباشد خودکار باز می‌شود؛ اگر در دسترس نباشد دانلود در مرورگر ادامه پیدا می‌کند

**نصب (Chrome / Edge):**

1. برنامه را یک بار اجرا کنید؛ افزونه خودکار ثبت می‌شود (تنظیمات ← مرورگر).
2. `chrome://extensions` یا `edge://extensions` را باز کنید و **Developer mode** را روشن کنید.
3. **Load unpacked** را بزنید و پوشهٔ `extension` کنار برنامه را انتخاب کنید (در تنظیمات ← مرورگر دکمهٔ «باز کردن پوشه» هست).

**Firefox:** محتوای `extension/` را کپی کنید، `extension/firefox/manifest.json` را جایگزین `manifest.json` کنید و از `about:debugging` ← This Firefox ← Load Temporary Add-on بارگذاری کنید (یا با `web-ext` امضا کنید).

ارتباط: افزونه ← `SmartDownloadManager.Host.exe` (Native Messaging، stdin/stdout) ← named pipe ← برنامه. شناسهٔ افزونهٔ unpacked ثابت است (`hlmploemhlgmkommeccngdhdpjggjcdi`)؛ نسخهٔ منتشرشده در Web Store را می‌توانید در تنظیمات ← مرورگر به‌عنوان شناسهٔ اضافه وارد کنید.

## ساختار پروژه

```
src/SDM.Core     موتور دانلود، صف، تشخیص‌دهنده‌ها و انتقال فایل (بدون وابستگی به ویندوز)
src/SDM.App      رابط کاربری WPF
src/SDM.Cli      خط فرمان
src/SDM.NativeHost  واسط افزونهٔ مرورگر (Native Messaging)
extension/       افزونهٔ مرورگر (Manifest V3)
tests/           تست‌های xUnit (شامل یک سرور HTTP محلی برای تست Range و Resume)
```

## ساخت و اجرا

پیش‌نیاز: [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

```powershell
dotnet build SmartDownloadManager.sln
dotnet run --project src/SDM.App          # رابط کاربری (فقط ویندوز)
dotnet test tests/SDM.Core.Tests          # تست‌ها (ویندوز، لینوکس یا مک)
```

خط فرمان:

```powershell
dotnet run --project src/SDM.Cli -- get https://example.com/file.zip --out D:\Downloads
dotnet run --project src/SDM.Cli -- classify "Dark.S01E03.1080p.mkv" "Dune.Part.Two.2024.2160p.mkv"
```

در خط فرمان، `Ctrl+C` دانلود را متوقف می‌کند و پیشرفت را ذخیره می‌کند. اجرای دوبارهٔ همان دستور، دانلود را ادامه می‌دهد.

### انتشار نسخهٔ جدید

یک تگ بسازید و Push کنید؛ GitHub Actions نصب‌کننده، نسخهٔ پرتابل و `SHA256SUMS.txt` را می‌سازد و Release را منتشر می‌کند. برنامه‌های نصب‌شده خودشان نسخهٔ جدید را پیدا می‌کنند.

```powershell
git tag v0.4.0
git push origin v0.4.0
```

ساخت دستی نصب‌کننده (نیاز به [Inno Setup 6](https://jrsoftware.org/isinfo.php)):

```powershell
dotnet publish src/SDM.App -c Release -r win-x64 --self-contained true -o publish
iscc /DAppVersion=0.4.0 /DSourceDir=..\publish installer\SmartDownloadManager.iss
```

## تنظیمات

تنظیمات در `%AppData%\SDM\settings.json` ذخیره می‌شوند. نمونهٔ یک موضوع:

```json
{
  "DownloadDirectory": "D:\\Downloads",
  "SeriesDirectory": "D:\\Series",
  "Rules": [
    { "Name": "Dark", "Keywords": ["dark"], "TargetFolder": "D:\\Series\\Dark", "SeasonSubfolders": true },
    { "Name": "Dev", "Domains": ["github.com"], "TargetFolder": "D:\\Dev" }
  ],
  "MaxSegments": 32,
  "RenameToStandard": true,
  "Ai": { "Provider": "Claude", "ApiKey": "sk-ant-...", "Model": "", "BaseUrl": "" },
  "TmdbApiKey": "...",
  "MediaServer": { "Type": "Emby", "Url": "http://localhost:8096", "ApiKey": "...", "RefreshAfterDownload": true }
}
```

## محدودیت‌ها

- کلیدهای API فعلاً به‌صورت متن ساده در `settings.json` (داخل پروفایل کاربر) ذخیره می‌شوند.
- اگر Emby روی سیستم دیگری اجرا شود (مثلاً NAS)، مسیر کتابخانه‌هایش روی این کامپیوتر وجود ندارد و پیشنهاد به پوشه‌های خود برنامه برمی‌گردد.

- SDM محتوای محافظت‌شده با DRM (مثل Widevine، PlayReady و FairPlay) را دانلود نمی‌کند و چنین محتوایی را فقط تشخیص می‌دهد.
- مسئولیت رعایت قانون کپی‌رایت و شرایط استفادهٔ سایت‌ها با کاربر است.
- دانلود از سایت‌های ویدیویی و دانلود خودکار زیرنویس عمداً پشتیبانی نمی‌شود.
- فونت پیشنهادی رابط کاربری [Vazirmatn](https://github.com/rastikerdar/vazirmatn) است؛ اگر نصب نباشد از Segoe UI استفاده می‌شود.
